## 🚀 Live Preview / Usage
You can view the portfolio in two easy ways:

### Option 1: Direct Browser Open
Simply double-click [`index.html`](index.html) or right-click and choose **Open with > Chrome / Edge / Firefox**.

### Option 2: Local Web Server
If you prefer running a local static server:
```bash
npm start
```
or
```bash
npx serve .
```

## 🌐 Deploy to GitHub Pages / Vercel
1. Create a new repository on your GitHub account: `https://github.com/new` named `portfolio`.
2. Push this folder to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/Sayani-Santra/portfolio.git
   git push -u origin main
   ```
3. In your GitHub repo settings, enable **GitHub Pages** (Deploy from Branch: `main` / `root`), or import it directly into **Vercel** / **Netlify** for free instant hosting!
